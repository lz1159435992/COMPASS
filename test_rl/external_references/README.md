# External References Directory

This directory contains **placeholder files** for external data dependencies referenced by the COMPASS codebase.

## Quick Start

All external file paths are now centralized in `config.py`. To use your own data:

```bash
# Option 1: Place files in this directory (default)
cp /path/to/your/info_dict_rl.txt ./

# Option 2: Set environment variables to override paths
export INFO_DICT_RL=/path/to/your/info_dict_rl.txt
export INFO_DICT_PREDICTOR=/path/to/your/info_dict_predictor.txt
```

## Required External Files

### 1. `info_dict_rl.txt`

**Config key**: `config.get_external_file('info_dict_rl')`

**Purpose**: Maps SMT file paths to RL-related features for training the constraint selection policy.

**Format**: Text file with one entry per line, or JSON dictionary:
```
{"/path/to/smt/file.smt2": [feature1, feature2, ...], ...}
```

**Referenced by**:
- `test_rl/test_group_gai_6_llm_add_ce_predictor_SMTimer_docker_info_dict_rl.py`
- `test_rl/test_group_gai_6_llm_add_ce_predictor_SMTimer_docker_info_dict_rl_llm_only_v2.py`
- `test_rl/test_group_gai_6_llm_add_ce_predictor_SMTimer_docker_info_dict_rl_random_1223.py`
- `test_rl/predictor/*.py`

### 2. `info_dict_predictor.txt`

**Config key**: `config.get_external_file('info_dict_predictor')`

**Purpose**: Contains predictor training data mapping SMT files to solver performance labels.

**Format**: Text file with solver selection labels and timing data.

**Referenced by**:
- `test_rl/predictor/test_group_get_dis_smt_comp.py`
- `test_rl/smtimer_experiments/*/run_predictor.py`

### 3. `result_dict_time.txt`

**Config key**: `config.get_external_file('result_dict_time')`

**Purpose**: Stores timing results from solver benchmark experiments.

**Format**: Text file with solver execution times per SMT instance.

## Data Directories (Environment Variables)

Set these environment variables to override default data locations:

| Variable | Default | Description |
|----------|---------|-------------|
| `SMT_DATA_ROOT` | `/tmp/smt_data` | Root for SMT benchmark datasets |
| `SMT_ALT_DATA_ROOT` | `/tmp/smt_data` | Alternative data root (formerly `/home/nju/Downloads`) |
| `SMT_CLOUD_DISK_PREFIX` | `/tmp/cloud_disk` | Cloud-mounted data prefix |
| `BVPARTI_HOME` | `test_rl/AriParti_sync` | BVParti solver installation |
| `ARIPARTI_HOME` | `test_rl/AriParti_sync` | AriParti solver installation |

## Generating Data Files

### info_dict_rl.txt
This file is generated during RL training. Each entry maps an SMT file path to its extracted features:
```python
{
    "/path/to/instance.smt2": [0.5, 1.2, 3.4, ...],
    ...
}
```

### info_dict_predictor.txt
Generated by running the predictor training pipeline on labeled SMT instances.

### NIA.json / QF_NIA_test.json
Download from SMT-COMP or generate from your own benchmark sets.

## Pre-computed Feature Caches

The directory `test_rl/predictor/smt_comp_features/` contains pre-computed BERT embedding features for SMT-COMP benchmarks. These are **derived data** that can be regenerated:

```bash
# Generate features for a specific theory (e.g., QF_NIA)
python test_rl/predictor/test_group_get_dis_smt_comp_1000.py \
    --theory QF_NIA \
    --output test_rl/predictor/smt_comp_features/
```

**Note**: This directory is listed in `.gitignore` due to its large size (~713MB, 31,000+ files). Feature caches will be generated automatically on first run if the benchmark SMT files are available.
